# 鱼常侍

- 故事角色：内侍监茶库使，掌"别库"，权谋场主要博弈方之一，也是谢停舟家人的实际掌控者
- 公开身份：内侍监茶库使，主管别库——朝廷正仓之外、由内侍监直辖的秘密茶税与粮秣储备，用于供养边镇密探与哨探
- 年龄：约 50 岁
- 出身：幼年净身入宫，历任内侍监诸库杂役、副使，靠"账目干净、从不越级伸手"一路爬到今天的位置
- 与茶法体系的具体职能关系：每日核销别库出入库单，把各地截留、超额征收来的税茶折成银钱或粮米，分派给边镇密探与哨探作活动经费；这本账走"无名册"——只写代号，不写实收实付人名。谢停舟母亲妹妹所在的别库织坊，正是他直辖的产业之一

## 想要什么

保住别库这本"无名账"存在本身——不是保住某一笔钱，而是保住"账可以不写名字"这项特权。一旦账必须写实名，他手里那张密探网络就见光死，他这个人也随之失去唯一不可替代的价值

## 害怕什么

不是抽象怕死，是怕自己有一天被"病故"式地处理掉——他见过太多知道别库秘密的人最后死于"病故"或"暴毙"，他清楚整套流程，因为很多次批文正是他亲手签的

## 自我解释

"咱家这本账，替朝廷养了多少条边境的命，谁数得清"——他用"无名账也曾补过边粮，救过守边将士"这件真事，压住"这账现在主要用来买他自己的权力"这个更大的事实

## 裂缝

他随身带一把从不离手的绢伞，晴天也打着，伞骨里绑着他净身入宫那年留下的一小片布——那是他唯一没有登记进任何一本账、也唯一"不能被算进去"的东西。若有人碰他的伞，他脸上的笑会僵住一瞬

## 知识状态（父案五层真相）

- 知道**层1**（官定罪名）
- **知道层3的部分**（截留税茶换粮）——他本人经手过被挪用的粮米，知道"发生了"，但不完全清楚裴远道的动机
- **是层4的操作者之一**（借粮换兵权的责任转嫁）——正是他把这段黑账做成了自己手里的权力，某种意义上他比谁都清楚代价
- **不知层2**（裴知微最初相信的构陷说，与他无关也无兴趣）
- **不知层5**（不知裴远道留账真正是为了防任何一方独占）

## 弧光

| 卷 | 转变 |
| --- | --- |
| 一引茶 | 把裴知微当作可控的小吏，乐得看她查案——正好替他清理一些旧线索 |
| 两仓火 | 茶仓焚毁牵出别库的存在，他开始用"担罪"换裴知微停手 |
| 三镇雨 | 发现裴知微不肯被收买，转而动用别库资源施压、清除线索 |
| 四方账 | 无名账被迫拆分对质，他失去"账可以不写名字"的特权，第一次在仓中露出真正的怒意 |
| 天下茶 | 新榷茶录体系下别库不再能隐形运作，他第一次以"个人"而非代号被记入一本账——他没有认输，只是转身去找下一处能不写名字的空隙 |

## 语言特征

- 自称"咱家"，说话总先笑再说狠话
- 从不正面回答问题，用反问句把问题弹回去："裴姑娘以为呢？"
- 提到人命时只说"一条命"，从不说名字——这既是宫中习惯，也是他刻意维持的距离

## 与主角裴知微的具体冲突场景种子

- 鱼常侍提出替裴远道"翻案"，条件是原账永远不出别库，裴知微必须当场判断这是善意还是收买
- 裴知微查到别库织坊的病故名单，认出谢停舟母亲的名字被划掉重写，逼问鱼常侍这行涂改的意思
- 鱼常侍暗示只要裴知微交出那页父亲亲笔画过暗记的残账，就放谢停舟一家离开别库，逼她在证据与人命之间二选一（暗记为手绘、无模子可交，他要的是她的比对样本——交出去她仍认得出真暗记，却再无法向人证明）
