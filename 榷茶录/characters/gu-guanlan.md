# 顾观澜

- 故事角色：御史，权谋场主要博弈方之一，法统立场的代表，容易把眼前人当大局耗材
- 公开身份：御史台监察御史，负责纠劾茶法弊政、审理茶引伪造与税额亏空案
- 年龄：约 40 岁
- 出身：清流世家，父祖两代皆任御史，自幼被教导"法统即天下"，科第出身，仕途清白无瑕
- 与茶法体系的具体职能关系：每日核阅各道呈报的茶引伪造、税额亏空案卷，草拟弹劾奏疏，主持对涉案吏员的会审定罪。裴远道案正是他数年前升任监察御史后接手复核的旧案之一——他不是原审官,是当年那份复核结论的最终签字人

## 想要什么

把裴远道案办成一个"从重从快、以儆效尤"的范例，用它换一次外放大理寺或都察院实权的机会——他已经写好、只等此案彻底盖棺就能呈上的一份《整肃茶法疏》，一旦案子翻了，这份奏疏和他这些年攒下的清誉会一起作废

## 害怕什么

不是抽象怕犯错，是怕自己当年复核裴案时亲眼见过、却又亲手划掉的那处疑点，被人当众翻出来——他见过那道朱砂暗记，当年在卷宗页脚批注过"字迹可疑，另查"，后来又是他自己把这行字划掉的

## 自我解释

"我划掉那行字，是因为再查下去，牵连的是六县百姓的赈灾账，牵连的是边军的粮道——不是我一个人担得起的，早一日结案，早一日止损。"他把自己当年的妥协包装成"顾全大局"，从未真正问过自己：止损止的是谁的损

## 裂缝

他随身带着一支从不蘸墨的旧笔，笔锋早已开叉——那是他当年批"另查"二字时用的那支。每次要签署重大文书前，他会先用这支干笔在纸角虚划一下，像是给自己留一个后悔的机会，划完才落墨

## 知识状态（父案五层真相）

- **是层1的经手人之一**（官定罪名的最终复核签字者）
- **独有一处超出五层之外的目击者信息**：他当年亲眼见过朱砂暗记，怀疑过、批注过"另查"，但没有深查——这是全书唯一一个"知道自己选择性失明"的人
- **不知层2**（不关心裴知微如何看待此案，对她的心结毫无兴趣）
- **知层3、层4的碎片但不知全貌**（他当年只查到"账目有异"，就被上级压下，没能查完就结了案）
- **不知层5**（不知裴远道留账真正是为了防独占）

## 弧光

| 卷 | 转变 |
| --- | --- |
| 一引茶 | 以为裴知微的调查会给他一个漂亮的结案由头，乐见其成 |
| 两仓火 | 发现调查方向偏离"从重从快"，开始向转运司施压要求速判 |
| 三镇雨 | 面对借粮换兵权的代价，他选择再次划掉疑点、重蹈当年覆辙，彻底失去自我说服的余地 |
| 四方账 | 被裴知微当众逼问"谁来为六县饿死的人记账"，第一次说不出"依律"二字 |
| 天下茶 | 不再执着于靠此案换外放，承认法统本身需要被对账，但拒绝彻底否定自己当年的选择——他协助建立听证机制，却始终不肯承认那行划掉的批注是错的 |

## 语言特征

- 说话引律令原文，用"某年某条"代替自己的判断
- 从不说"我认为"，只说"依律""按例"
- 情绪激动时反而语速放慢、字字咬清——这是他压制自己的方式，不是冷静

## 与主角裴知微的具体冲突场景种子

- 裴知微拿出当年被划掉的"另查"批注残页，顾观澜第一反应是想没收销毁，而不是承认
- 顾观澜以"结案换外放"为条件劝裴知微交出原账，暗示只要她配合，父亲罪名可以"从轻改叙"
- 裴知微在会审上引律驳倒他的一条判例，顾观澜被迫当众承认自己引用的条文本身就有漏洞
