# 裴知微

- 故事角色：主角，全书视角人物
- 公开身份：淮南转运司验引所验引茶吏（隐姓改籍入职，官面履历上不是裴远道之女）
- 年龄：22 岁
- 出身：本是淮南茶商世家、其父裴远道曾任转运司都句院勾覆官（专司核算茶引与税额），获罪抄家后家产充公、母早逝，她由旧仆掩护改名换籍，三年后凭识账认引的手艺考入转运司验引所做最底层吏员
- 与茶法体系的具体职能关系：每日辰时到验引所当值，逐张核验茶商呈缴的茶引——先摸纸质真伪，再验朱印色泽是否晕染均匀，再翻验引簿逐行核对引号、持引人姓名、缴税日期是否对得上，核对无误才在引券背面签字画押、盖验讫戳放行；查出可疑引券则扣货、传仓吏复核。当值之余，她要把当年整理不完的旧引存根重新誊清、归档进转运司架阁库——这也是她最初申请这份差事的理由：架阁库里存着能证明父亲清白或有罪的旧账残页

## 想要什么

拿到一份完整的、能证明父亲无罪的原始账册——具体到她贴身收着的**一页父亲亲笔画过暗记的残账**。

**注意（正典）**：暗记是**手绘**的，父亲校账不用家印、不用私印，只用手画的三点斜朱砂。所以世上不存在"暗记的模子"——不可仿的不是一枚章，是落笔的顺序、三点之间的间距、和第三点上那一道几乎看不见的回锋。她能认，是因为小时候替父亲晒账页时看过几百遍。

那页残账是她唯一的比对样本，也是她能向旁人**证明**自己认得对的唯一凭据。一旦被没收，她仍然认得出真暗记，却再也没法让别人相信她认得出——她会从"持证者"跌回"空口说白话的罪臣之女"。这一层区别是全书成长线「手艺」的起点：到后卷她要走到不需要样本、她本人就是样本的位置。

## 害怕什么

不是抽象地"怕真相"，而是具体一件事：怕自己按律签字放行或扣押的某一张引，会像"梁肃引"一样牵连出更多不相干的茶户被抄家问罪——她亲手画的那个押,会变成压垮别人的新罪证

## 自我解释

她告诉自己"我只是照律核验，错的是造假的人，不是我"；但每一次按律扣押一批茶货，她都要先在心里编好一整套说辞，证明这不是私怨，只是为了保住自己还能留在转运司、还能接着翻父亲案子的立场。她用"依律行事"这四个字，压住自己其实在利用职权查私案的事实

## 裂缝

她随身带着一个装着"茶末"的小布囊，其实里面不是茶叶，是当年抄家那夜她从父亲书案上抢出来的、被烧剩的一撮账灰。她自己说不清留着它做什么——账灰验不出任何字迹——但每次紧张或被人逼问父亲的事，她的手指会不自觉伸进袖口摩挲布囊的边角

## 知识状态（父案五层真相）

- 知道**层1**（官定罪名：伪造茶引、通藩、侵吞税茶）——这是压在她身上的枷锁，全城皆知
- **相信层2**（她最初以为的版本：父亲因发现别库亏空而被构陷）——这是她入职查案的出发点，也是全书要被逐步推翻的错误信念
- **不知层3**（大旱年截留税茶换粮、救六县茶户）——卷二《两仓火》茶仓火起时才亲眼见到证据
- **不知层4**（向淮南借粮、默认茶道换兵权）——卷三《三镇雨》借粮契约现世才知晓代价
- **不知层5**（父亲留账是为了防任何一方独占真相）——直到卷四、卷五才彻底想透

## 弧光

| 卷 | 转变 |
| --- | --- |
| 一引茶 | 坚信父亲被构陷，把每一条线索当武器，只想找到能洗冤的那一张纸 |
| 两仓火 | 亲眼见到截留赈灾的证据，"我以为的父亲"第一次崩塌，开始怀疑自己有没有资格论对错 |
| 三镇雨 | 得知借粮换兵权的代价，被逼在"揭发换清白"与"沉默换安稳"间表态，她选择继续查而非收手 |
| 四方账 | 直面鱼常侍、韩令仪、顾观澜三套各自成立的道理，拒绝再充当"谁对谁错"的裁判，转而设计分账对质 |
| 天下茶 | 不再追求个人清白，选择公开、分散原账，主动承担真相引爆之后的一切代价 |

## 语言特征

- 习惯用"按律""账上写的是"开头压住情绪，把私人立场包在公事口吻里
- 从不说"我觉得"，只说"账上没有这一笔"——用账目代替判断
- 紧张或被逼问时会把一句话拆成两半，中间停顿去看对方的手（怕看见递来的金子或藏着的凶器）

## 与他人的具体冲突场景种子

- 与谢停舟：她要他交出一封他明知内容敏感却已经收钱送出的密信，他拒绝，因为"送到的信不能要回来"是他唯一守的规矩
- 与阿蘅：她按律要没收阿蘅那本"私账"作为查案物证，阿蘅宁可烧掉也不给，两人第一次正面撕破脸
- 与顾观澜：她当众逼问他当年批注"字迹可疑、另查"却又亲手划掉的那行字，顾观澜被迫在众人面前解释自己的沉默
