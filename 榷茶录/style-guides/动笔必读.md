# 动笔必读（执笔单页）

> 这一页是给**执笔**的。规划、改稿、立新规矩仍以 `project-voice.md`（这一句怎么写）与 `叙事节奏-爽点兑现.md`（这一章怎么搭）为唯一事实源，**两者冲突以节奏细则为准**。
> 正典事实查 `continuity/canon.md`。写完跑 `python tools/lint.py <正文路径>`。

## 一、机械红线（脚本会扫，零容忍）

| 项 | 要求 |
| --- | --- |
| 破折号 `——` | **零次** |
| "仿佛""如同" | **零次** |
| 半角逗号 | **零次**，全文中文标点 |
| "终于明白""才明白""心头一X""隐约觉得" | **零次**（叙述者替人物宣布结论） |
| 正红一系（朱红殷红通红血红绯红正红赤红） | **零次**。官印印色写"橘调深红"、墨底写"暗红光泽"是第 1 章原措辞，属正当用法 |
| 元叙述（"第十七章""本章""上一卷"） | **零次**，正文里不许出现章号 |
| 长度 | **含标点 2250–2750**（约合汉字 2050–2250）。汉字数只作参考 |

## 二、唯一禁区

**温度片刻处不写解释。** 人物可以有反应，**不许有结论**，不许由叙述点破，不许她在心里想明白。

已入册的范本：卷一第 1 章挑夫、第 3 章找零新钱、第 5 章阿蘅烘鞋、第 8 章多送一程、第 18 章灶边那一小块干净地面、第 21 章那扇没有闩的门。

同类规矩还有几条硬的，见 `canon.md` 第七节「知识状态与禁区」，动笔前扫一眼。

## 三、温度分档（决定句法）

| 分档 | 句法 | 内心戏配额 |
| --- | --- | --- |
| **冷场** | 短句为主，多留白，**只给硬物** | 少而硬，判断与手艺推演，一句就走。**冷场不等于删光内心戏** |
| **暖场** | 句子拉长，写气味、手势、没说出口的照拂 | 可舒展 |
| **权谋场** | 长短交替：**长句铺局势，短句落判断** | 潜台词大于台词，但人物心里不许是空的 |
| **高潮** | 不只靠断句。**先给一段完整、带呼吸的表达，说完再用短句收束**。抒情后面必须跟一个物件 | 允许一次真正的抒情，落点必须是具体的事 |

## 四、内心戏是必需品

禁的只是**叙述者越过人物替她宣布结论**。四个必写位置：

1. **自我辩解与自欺**
2. **手艺推演**（怎么验、怎么算、怎么排——要具体到可复核）
3. **由眼前之物勾起的短促闪回**（要短、要具体、说完立刻回到当下，**不许写成回忆段落**）
4. **她想说而没说的那半句**（**不许写成台词**）

## 五、写自欺时的两条禁令

- **不许用"顺"字收束**。卷一十六章里她五次自欺都用"顺"结尾，读者会认出公式，同一收束标记一卷内不超过两次。
- **"说到一半被别的事打断"这个替代写法，卷一第 19 章已用过一次**，别连着用。

其他换法：把说辞写进公文措辞里、换一个口径重说一遍、说服的对象改成一个想象中的问话人、干脆不收束。

## 六、光影颜色与通感

- 配色：墨黑／纸黄／茶青褐／雾白／灯焰橘。橙黄一系（灶火、油灯）不受限。
- **正红是保留色**，只归四样：父亲的暗记、官印验讫戳、血、以及她本人以父亲手法所下的私批（全书封顶三次，**卷一已用一次，另两次留给卷四、卷五**）。
- **通感每卷三四处封顶**，卷一已顶格。通感之后**必须紧跟动作**，不许接评论性总结。普通比喻不算通感，不占额度。

## 七、禁止非 A 非 B

伏笔种下前**答案必须定死并登记**。"故意悬置""保持暧昧""后面再定"一律视为未完成的工作。

## 八、写禁令时必须同时写清边界

一条纯禁令会误伤整个维度——"冷场删形容词"曾连带砍掉内心戏、光影、颜色。**每写一条约束，同一口气里写清它的边界与仍然允许的部分。**

## 九、执笔最爱犯的三种穿帮（每章自查）

1. **元叙述**：正文里直接写"第十七章那一叠东西"。
2. **时间**："旧年走过的辙痕"其实是同年三月；"昨日的影子"其实是十一天前。**凡写相对时间，回时间线核一次。**
3. **擅自扩写正典**：把家训"账要留三处退路"自作主张具体化成"给官给民给天"。**正典只在 `canon.md` 里，没写的不许自己补。**
