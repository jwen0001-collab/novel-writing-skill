# 《榷茶录》项目文风守则

> 本文件是项目的**文风唯一事实源**。规划、试写、正文、修订前必须先读本文件。
> 每次用户确认新的文风反馈，先更新此处，再动笔。

## 目标读者效果

读者读完一场戏，应当记住的是**一个具体的动作或物件**（一枚金铤、一道朱砂暗记、一只空茶篓），而不是一句金句。
情绪从"账"里长出来：数字先是数字，最后变成人名。

## 场景温度分级（核心规则）

写每一场戏之前，先判定它属于哪一档，再定句法。

| 温度 | 句法 | 细节策略 | 参照物 |
| --- | --- | --- | --- |
| **冷场**（验引、对质、刑讯、死讯、朝堂裁决） | 短句为主，多留白，少修饰语；能删的形容词一律删 | 只给硬物：纸、印、墨色、刀口、雨点 | 像账页、雨声、刀锋 |
| **暖场**（茶户家里、夜里烤火、师徒、旧物、并肩赶路） | 句子拉长，允许从句和绵延的呼吸 | 写气味、手势、茶烟，写人物**没说出口的照拂** | 灶上水汽 |
| **权谋场**（衙署交锋、谈判、试探、结盟） | 长短交替：**长句铺局势，短句落判断** | 信息密度高，潜台词大于台词 | 一局棋 |
| **情绪高潮** | 不只靠断句。先让人物有**一段完整、带呼吸的表达**，说完，再用短句收束 | 高潮处允许一次真正的抒情，但落点必须是具体的事 | 先开口，后落刀 |

## 读者爽点节奏（与温度分档并列的第二条节拍器）

温度管的是"这一场怎么写"，爽点管的是"读者凭什么继续读"。两者独立计算，不要混为一谈。

### 核心节拍

- **每 3–5 章必须有一个小爽点。** 定义：读者**通过裴知微**获得的一次明确正反馈。不是氛围好，是她赢了、她被承认了、她护住了谁。
- **每一卷的大剧情必须有一个大爽点。** 卷末的不可逆转折不能只是"更惨了"或"更复杂了"，必须同时兑付一次读者等了一整卷的畅快。
- **负面事件负责张力，不负责兑付。** 死亡、构陷、失败、被夺权只能拉紧注意力；张力拉紧后必须在 3–5 章内给出一次兑付，否则读者只剩疲惫。

> 参照通用机制：死亡负责张力和注意力，重生负责"强大 / 重来 / 报仇"的兑付。本书没有重生，所以兑付必须由下面这套货币承担。

### 本书的爽点货币（按爽感强度排序，可叠加）

| 类型 | 长什么样 | 强度 | 是否需要预埋 |
| --- | --- | --- | --- |
| **破局** | 满堂人看不出的破绽，她一眼看出；一句话戳穿一整套账 | 小～中 | 否 |
| **技能习得** | 她学会一门新手艺：辨纸辨印、勾稽两本对不上的账、看茶青识产地、听讼审词、骑马、认路。学会之后**必须在 2 章内用上一次**，读者才拿得到"她变强了"的兑付 | 小～中（累积后为大） | 否 |
| **护住具体的人** | 一户茶农的茶山保住了、一个挑夫没被扣、阿蘅的私账没被抄走 | 中 | 是（先让读者在意这个人） |
| **打脸** | 曾当众看轻她的人（因她是女子、是小吏、是罪臣之女），被她当着同一批人证明看错了 | 中～大 | **是（必须先写足那次轻视）** |
| **以术压人** | 当众对账，让位高者当场答不上来、下不来台 | 中～大 | 否 |
| **身份被认** | 罪臣之女的身份被人明知而不弃：有人替她挡、有人叫她"裴吏"而不是"裴远道的女儿" | 中～大 | 是 |
| **旧账现报** | 前文欺压过她或茶户的人，被她用规则本身按住 | 大 | 是 |
| **父亲被追平** | 她做出一件父亲当年做过的事，并且做得比他干净 | 大（稀有，全书不超过四次） | 是（跨卷） |

### 打脸的写法纪律

打脸是本书最容易写崩的一格，四条硬规矩：

1. **轻视必须先写足，且要有名有姓。** 不许用"众人窃笑"这种无主语的轻视来凑；必须是某个具体的人、说了具体的话（"一个验引的小娘子，也配翻转运司的旧账"）。
2. **打脸靠事实，不靠嘴。** 她不反驳，她把那张引券翻过来给他看。让对方自己把话咽回去。
3. **不写围观者的赞叹。** 不许出现"四下哗然""众人这才明白她的厉害"。写对方的手、对方的停顿、对方改口的那半句。
4. **被打脸的人不能变蠢。** 他必须是按他自己的道理行事，只是他的道理里没有她这一种人。

### 成长线（贯穿全书的慢速兑付）

小爽点是单次的，成长线是全书最大的一次兑付，必须能被读者感知到进度。分三条并行推进：

| 线 | 起点（卷一） | 终点（卷五） | 读者怎么看见进度 |
| --- | --- | --- | --- |
| **手艺** | 只会验引：看纸、看印、看人 | 能凭残账重建一整套勾稽关系，反过来设计账 | 每卷至少一次「上一卷她做不到的事，这一卷她做到了」的镜像场景 |
| **权位** | 无品验引茶吏，俸米不够养一匹好马 | 有资格召集多方对账、说话能定事 | 每卷她能调动的人和能进的门槛各高一级 |
| **认知** | 求父亲的清白，信真相天然正义 | 承担复杂真相，明白账留在一个人手里就会再欠一次命 | 每卷她被迫放弃一个曾坚信的东西 |

**镜像场景是成长线的主要兑付手段**：把卷一她被拦在门外、被拿走引券、被杜谦按住手的那些屈辱场景，在后卷用几乎相同的场面重演一次，由她占上风。同一个地点、同一个动作、结果相反。

**成长必须有代价。** 每一次她变强，都要付出一样具体的东西：一个盟友的信任、一条退路、一次她本可以救的人。不许无代价升级。

### 使用纪律

1. 小爽点**必须落在具体的物或人身上**，不许写成"她感到一阵久违的畅快"。爽感由后果承载：那张假引被扣下、那户茶山留住了、那个人当众闭嘴。
2. 爽点**不必是暖场**。当众对账把杜谦按住是权谋场，一样是爽点；暖只是爽点的一种实现方式，不是唯一。
3. **不要把爽点全押在卷末。** 卷内三到五章一小口，卷末一大口。连续 6 章没有兑付即为节奏事故。
4. 大爽点之后立刻抬价：兑付完成的同一章或下一章，必须让读者看见这次胜利的代价或新敌人。爽完不收，读者会松掉。
5. 爽点强度要爬升。卷一的最大爽点不得高于卷三，卷末大爽点逐卷加码，终局一次到顶。

## 心理描写与独白（要写，但要分清两种东西）

本书是第三人称限知、紧贴裴知微。**内心戏是必需品，不是违规品**。此前"少写心理"的说法收得过紧，现更正如下。

真正要禁的从来不是内心活动，而是**叙述者越过人物、替她把结论宣布出来**。这是两件事：

| | 要写 | 不要写 |
| --- | --- | --- |
| 判断 | 她权衡的**过程**：该扣还是该放、这一笔按律该怎么措辞、硬要会不会把话逼死 | 「她终于明白杜谦是鱼常侍的人」这类由叙述者交付的结论 |
| 情绪 | 情绪的**由来与身体**：手指发凉、话到嘴边咽回去、想说的那半句 | 「她心头一暖」「一阵快意涌上来」这类贴标签 |
| 认知 | 她**当下能想到**的那一层，包括想错的那一层 | 叙述者知道后文、暗示读者"她还不知道……" |
| 意义 | 让读者自己得出 | 替读者总结主题 |

### 该写内心戏的四个位置

1. **自我辩解与自欺**。裴知微用"依律行事"四个字压住自己其实在利用职权查私案——这层自我说服**必须上纸**，否则她只是个正确的人，不是个活人。她越是替自己编说辞，读者越心疼。
2. **手艺推演**。她验引、算账、比对时的心里话，是本书最好看的部分之一。这不是心理描写的例外，这就是她这个人。写她怎么怀疑自己算错、怎么换一个口径再核一遍。
3. **记忆闪回**。父亲、账页、抄家那夜。**闪回要短、要具体、要由眼前的物勾起**，不要成段回忆。已认可的高潮试写就是范例：父亲灯下教她算账那一段，由眼前摊开的父亲笔迹勾起，说完立刻回到雨里。
4. **她想说而没说的那句话**。权谋场尤其要写——潜台词优先不等于人物内心是空的，恰恰相反，读者要知道她咽回去了什么。

### 按温度分档的配额

- **冷场**：内心戏少而硬，多为判断与手艺推演，一句就走，不缠绵。
- **暖场**：可以放开写。这是她少数不设防的时刻，允许绵延的感受和没说出口的话。
- **权谋场**：内心是算计。写她读对方的动作、掂量自己该说哪一半，密度可以高。
- **情绪高潮**：**允许一整段独白**。这与「高潮先完整表达再短句收束」是同一条规则的两面——人物可以把话说完，也可以把心里话想完。

### 唯一保留的禁区

**温度片刻处不写解释**。阿蘅烘鞋、谢停舟挑新钱找零、挑夫的茶篓——这几处的力量全在"没说出口"上，一旦由叙述解释因果或由裴知微在心里点破，立刻塌掉。她可以有反应（把道谢咽回去、指尖捻着那几枚钱），但不许有结论。

## 光影、颜色与通感（要有，但要省着用）

前述"冷场只给硬物、能删的形容词一律删"收得过紧，把光影与颜色一并挤掉了。更正：**氛围是必需品，只是不能泛滥**。

### 本书的固有配色

不必另造，题材自带一套，写的时候从这里取：

| 色 | 来源 | 用在哪 |
| --- | --- | --- |
| 墨黑 | 墨、松烟、夜、皂色公服 | 冷场底色 |
| 纸黄 | 账页、旧卷、毛边纸、窗纸发白 | 架阁库、案头 |
| 茶青褐 | 茶叶、湿叶、茶籽壳、篓 | 码头、茶山 |
| 雾白 | 淮水的雾、烟、水汽、更鼓后的白 | 开篇与转场 |
| 灯焰橘 | 油灯、灶膛、火把 | 暖场与夜戏 |
| **朱砂红** | **父亲的暗记、验讫戳、血** | **见下，special** |

### 红是留着的

**朱砂红不许乱花。** 全书的**正红一系**（朱红、朱砂、殷红、血红、丹）只属于三样东西：父亲手画的三点暗记、官印与验讫戳、血。别处要这种红，用别的说法绕开（赭、绛、锈、褪色的桃）。

**橙黄一系不在此限**：灶火、油灯、火把该怎么写怎么写，橘红、暖黄、金都可以用。禁的是那一点**朱砂**，不是所有暖色。已有的合规用例：
- 第 1 章官印"橘调深红，比寻常朱砂暗一分"（官印，正当）
- 第 1 章茶引墨底"一层暗红光泽，是松烟里掺了朱砂粉"（官定用墨，正当）
- 第 5 章灶膛"映得屋里一片橘红"（火光，橙黄一系，正当）

这样一来，读者读到一百章时会形成条件反射：**红一出现，就是账、权、或死**。这是配色本身在承担主题，不必任何人点破。

### 用量纪律

- **一场一笔。** 每场戏给一处光影或颜色，通常放在**进场**或**收场**。不要通篇铺陈。
- **要跟着人物的注意力走。** 她在验引，就该注意到印色比寻常朱砂暗一分；她在灶边，才会看见火把屋里映成橘红。不要写她此刻不会看的东西。
- **冷场的颜色是冷的、脱色的**：雾、白、墨、铁、湿石头。短句给，一句就走。
- **暖场的颜色可以饱和、可以长**：灶火、茶烟、烘暖的鞋、窗上透出的光。这是全书少数允许铺陈的地方。
- **权谋场少用色，多用光**：谁在明处、谁在暗处、光从哪边来、谁的脸背着光。光影在这里是权力的示意图。
- **高潮可以放开**：雨、漏进仓里的光、被雨晕开的墨。

### 通感

允许，但**每卷不超过三四处**，且必须落在这本书自己的感官上：账的墨味、纸的手感、算珠声、茶的青气、雨声、铜铃。

已有的好例子（照此为准）：
- 算珠归位的声音"像雨点落进空瓮"
- 使费残页"半边字迹被水泡得晕开，像哭过一场"
- 山寨家家炊烟被风吹向一处，"像一整片山都在喘气"

**通感不许用来抒情**，只用来把一个抽象的东西变得可摸。写完立刻回到动作。

## 禁止非 A 非 B（最高级别纪律）

**读者可以不知道，作者不能不知道。**

任何伏笔、任何谜、任何"留白"，在种下之前，答案必须已经定死并写进 `continuity/` 或 `story-bible/`。种下之后才去想答案，就是故弄玄虚。

### 一律禁止的说法

- "故意永久悬置"
- "保持暧昧，不确认"
- "先留白，后面再定"
- "这个不急"
- "或 A 或 B，看后文需要"

以上出现在任何规划文件、章节纲、agent 回报里，都视为**未完成的工作**，不是风格选择。

### 分清两种"不知道"

| | 允许 | 禁止 |
| --- | --- | --- |
| 读者不知道 | ✅ 这是悬念，是本书的引擎 | |
| 人物不知道 | ✅ 知识状态本来就是分层调度的 | |
| **作者不知道** | | ❌ 这是没写完 |
| **同一条线有两种解释，作者未择一** | | ❌ 除非"两种解释并存"本身是已定死的设定，且写清了谁持哪一种 |

### 唯一的例外，且必须显式登记

如果某处的**答案就是"没有答案"**（例如：某人的动机连他自己也说不清），那么"没有答案"本身是一个决定，必须写进 continuity 日志，写清是谁、哪一处、为什么这里的空白是有意义的。**默认不允许，需要专门论证。**

### 执行

- 每次要写"待定""留白""后面再说"时，停下来，当场做决定，写进 continuity 日志
- 决定可以改，改了记一笔。**改决定是正常的，不做决定是失职**
- agent 回报里出现"保持暧昧""留待用户拍板"，主控必须当场定掉或明确向用户提一个二选一的问题，不许原样转述给用户当作进度

## 可执行规则

1. **暖场按需投放，不按章配额。** 开篇不允许是"查账—发现—质问"的一路硬节奏，但也不必每场都暖。裴知微与茶户、谢停舟、阿蘅之间要有能让人感到温度的片刻——目的是让后面的冷与痛有重量，以及让"护住具体的人"这一类爽点有兑付对象。**读者先在意这个人，夺走他才疼；先喜欢这个人，护住他才爽。**
2. **暖场不是休息场。** 一场暖戏也必须改变信息、承诺、亲密度或危险度之一（见 chapter-planner）。
3. **高潮处不要在人物最该说话时把他掐断。** 允许一段完整陈述；收束交给它后面的短句和一个动作。
4. **抒情后面必须跟一个物件。** 说完道理，就写手、写雨、写账页上晕开的墨。
5. **潜台词优先。** 权谋场里，人物真正的意思放在他不说的那半句里；不要用叙述解释他的动机。
6. **情绪温度靠对比制造。** 冷场之后紧接暖场，暖场之后紧接冷场；不要连续三场同温。
7. **数字要变成人。** 涉及账目、税额、粮数时，最终都要落到某个具体的人身上（六县灾民、几百户茶山）。

## 避免模式

- 冷场里堆形容词和比喻（"如同""仿佛"连用）。
- 用总结句替人物下判断（"她终于明白了……"）。
- 高潮全程碎句，不给人物完整说话的机会。
- 连续多章硬节奏，全无温度，读者对人物不产生依恋。
- 连续 6 章只有张力没有兑付（只堆惨、只堆谜、只堆更大的敌人）。
- 用叙述直接写爽感（"她心中一阵快意"），而不是用后果制造爽感。
- **把内心戏一并删光**。禁的是叙述者替人物下结论，不是人物有内心。没有自我辩解、没有手艺推演、没有咽回去的话，人物就是空的（见「心理描写与独白」一节）。
- 把爽点全部堆在卷末。
- 现代腔、翻译腔、AI 腔（并列排比堆砌、"不仅仅是…更是…"、破折号滥用）。
- 让叙述者比人物更聪明。
