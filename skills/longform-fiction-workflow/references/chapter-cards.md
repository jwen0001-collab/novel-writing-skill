# Chapter-card reference

Use this template when several writers, installments, or revisions must share the same narrative logic. Omit fields that have no decision value for the project.

```markdown
# [Installment title]

- POV:
- Time / place:
- Scene mode / temperature:
- Starting pressure:
- State change:

## Beats

1. Existing debt or desire enters the scene.
2. A person, institution, environment, or relationship applies specific pressure.
3. A concrete local result becomes possible or visible.
4. The result carries a cost, refusal, or counter-move.
5. End on an object, action, decision, or unanswered obligation that alters the next scene.

- Emotional / physical callback:
- Visible payoff:
- Concrete cost:
- Required elements:
- Forbidden outcomes:
- Continuity handoff:
```

## Review prompts

- What can each person do, refuse, or lose in this scene?
- Which fact is learned, which object changes hands, and who knows it afterward?
- Does the local result change the next chapter’s options?
- Is any explanation doing work that conflict, behavior, or material detail could do instead?
- Does the ending leave a specific obligation rather than a generic cliffhanger?
